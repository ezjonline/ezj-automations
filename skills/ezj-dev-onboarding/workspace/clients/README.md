# clients/

One folder per client, one repo per project inside it:

```
clients/
  todd-pritchard/
    todd-booking-funnel/
  ezj-online/          internal EZJ Online projects and dev trials
    dev-tryouts/
```

`/ezj-start-project <issue link>` creates these for you. Folder names are lowercase with hyphens. Never mix two clients' code, keys or data in one folder.
