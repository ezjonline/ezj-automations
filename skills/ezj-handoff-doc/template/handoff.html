How it worksWorking now

A missed call turns into a conversation

The phone system tells the bot a call was missed. The bot decides which text to send, sends it, and waits for a reply.

Set it up

Run it from zero in 5 steps

Everything you need to run it on a new account. No step needs Alex.

Download the code and install it
git clone https://github.com/EXAMPLE/harbor-dental && cd harbor-dental && npm install
Make your settings file

Then fill in the values from the table below.

cp .env.example .env
Run the tests

All 18 should pass before you go further.

npm test
Put it online

Copy the web address it prints at the end.

npx vercel deploy --prod
Point the phone number at it

Twilio → Phone Numbers → your number → "A call status changes" → paste your web address plus /api/missed-call → Save.

SettingWhat it isWhere to get itNeeded?
TWILIO_ACCOUNT_SIDThe ID of the phone system accountTwilio console, Account Info boxYes
TWILIO_AUTH_TOKENThe password for that account. Secret, never share it in chat.Same box, click "Show"Yes
TWILIO_FROM_NUMBERThe number the texts come fromTwilio, Phone NumbersYes
SLACK_WEBHOOK_URLWhere replies get postedSlack app settings, Incoming WebhooksYes
OFFICE_HOURSWhen the office counts as openYou choose. Example: Mon to Fri 08:00 17:00No, defaults to 8am to 5pm weekdays
MAX_TEXTS_PER_DAYTexts one caller can get per day before staff are alertedYou chooseNo, defaults to 2
Change the messages

Every text lives in messages.json. Edit the words, redeploy, done.

Change the hours

Set OFFICE_HOURS in Vercel settings. No code change.

Turn it off

Remove the web address from the Twilio number. Calls work normally again.

What breaks it

If something stops working

The three problems most likely to happen, and the fix for each.

You noticeA call is missed but no text goes out
WhyTwilio still points at an old web address.
FixRedo setup step 5 with the current address.
You noticeTexts show "undelivered" in Twilio
WhyUS phone carriers block business texts until the business is registered.
FixFinish the business registration in Twilio. It takes 1 to 3 days.
You noticeReplies stop showing in Slack
WhyThe Slack webhook was deleted or the channel was archived.
FixMake a new webhook, update SLACK_WEBHOOK_URL, redeploy.
