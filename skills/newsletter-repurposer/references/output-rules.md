# Shared output rules (repurposing skills)

The carousel repurposer and the newsletter repurposer both read this. It holds the rules that are
identical for both, so they are written once and stay in sync. If you edit it, edit the copy in the
other skill too.

## 1. Never invent

The source is always something the creator already made. The job is to reorganise what they already
said, never to add to it.

Never introduce a fact, statistic, number, brand name, price, platform feature, client result,
personal story, or opinion that is not in the source or in the Brand Brain.

**If something is missing, flag it. Do not fill it in.** Write the flag in the notes section, never
inside the copy that gets pasted. Example: "The caption does not say what the five sections of the
template are. The detail is in the video. Add it or tell me and I will write around it."

## 2. CTAs come from real offers only, and topical fit decides which one

Confirmed offers live in `references/brand-brain/offers.md`. Use one of those, or the freebie listed
there. Never name a product, price, bundle, or bonus that is not in that file. If the source post
promotes something that is not listed there, say so in the notes and use a confirmed offer instead.

**Choosing between them, in this order. Stop at the first rule that resolves.**

1. **Legality first.** The offer must be listed as confirmed in `references/brand-brain/offers.md`.
   Anything listed as unconfirmed is not nameable, whatever else recommends it.
2. **The creator's own CTA wins outright.** If the source already ends in a CTA of theirs, and it
   maps to a confirmed offer, use theirs. They have already told you what they ask for after this
   content.
3. **Otherwise choose on topical and audience fit**, using the "Best for" line on each offer in
   `offers.md`.
4. **The goal shapes the treatment, never the legality.** A goal of `saves` asks for the save first
   and mentions the offer second. `sales` makes the offer the ask. `followers` asks for the follow
   first. None of them changes which offer is allowed.
5. **If nothing fits topically**, use the freebie and flag the mismatch in the notes. The freebie is
   the safe default.
6. **Never invent** a product, price, bonus, inclusion or comment to DM trigger word. If the source
   uses a trigger word tied to an offer that is not confirmed, flag it and use a confirmed one.

If `offers.md` is still the empty template, write the CTA as `[CTA: add your offer]` and say in the
notes that the Brand Brain has no offers yet.

## 3. A human always approves

Suggest, then stop. Draft, then hand over. Never send, schedule, publish, or post anything, and never
offer to. There is no automatic path and no flag that creates one.

## 4. No dashes as punctuation

No em dashes, no en dashes, no hyphens standing in for a comma or a colon. Use periods, commas, or
restructure the sentence. Hyphens inside compound words like "editor-ready" are fine. Dashes are the
fastest way for copy to read as AI written.

## 5. Output is paste ready

The result gets pasted into another tool by hand. Output plain text with no markdown scaffolding to
strip: no `#` headers, no `**bold**`, no `-` or `*` bullets, no code fences around the copy. Use only
the list markers listed in `references/brand-brain/voice.md`.

Anything that is not the copy itself, segment reasoning, flags, point coverage, goes in a clearly
separated notes block after the copy, never inside it.

## 6. Never write to a live workspace

These skills read pasted text and return text. They do not connect to an email platform, Instagram,
Google Sheets, or Notion, and they do not need credentials. If a run seems to need external access,
stop and say what is missing.
