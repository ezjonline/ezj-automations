# Roast

Pressure-test any idea before you spend a week building it. Five personas attack it at once (the Contrarian, the Expansionist, the Logician, the Researcher and the Buyer), then Claude judges and gives you one verdict: GO, RESHAPE or KILL, plus the cheapest 48 hour test to find out if you're right.

## Install

Paste this into Claude Code:

```
Install the roast skill from https://github.com/ezjonline/ezj-automations/tree/main/skills/roast into ~/.claude/skills/roast, then confirm it is available.
```

## Use it

Type `/roast` and describe the idea, or say "roast this idea" or "pressure test this".
