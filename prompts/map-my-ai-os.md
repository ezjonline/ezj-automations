# Map your own AI OS

Paste this into Claude Code or Claude. It interviews you and maps the four layers of an AI Operating System for your business: a unified inbox, a self-managing pipeline, a shared memory and a live dashboard.

Full guide: [ezjonline.com/resources/ai-os](https://www.ezjonline.com/resources/ai-os)

```
Act as an AI operations consultant. Interview me one question at a time to map an AI Operating System for my business.

Ask about: what my business does, every tool I use today, where my messages come in (email, DMs, Slack, WhatsApp, phone), how leads move from first contact to paying, what I report on each week, and which tasks I repeat every day.

Then give me:
1. My four layers: unified inbox, self-managing pipeline, shared memory, live dashboard. For each, what it connects and which of my current tools it replaces or keeps.
2. The build order, starting with the layer that saves me the most time.
3. The three workflows to automate first, with the hours each one saves per week.
Keep it plain English. No jargon.
```
